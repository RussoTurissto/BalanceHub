# BalanceHub 1.1.3-rc6 — системные звуки и вибрация

- Встроенные WAV-мелодии теперь доступны через стабильные адреса в системной медиатеке Android
- Уведомления используют выбранный внутри BalanceHub звук и платформенную вибрацию
- Повторное изменение не создаёт новый канал, когда параметры уже совпадают
- Android-категории «Обновления», «Платежи», «События» сохранены
- Перестали сообщать об успехе до проверки фактических параметров Android
- Инструментальные тесты всех 15 звуков, сохранения каналов, реальных уведомлений и внешнего доступа к URI проверены на Android 10/15/16 (API 29/35/36)
- Проверены сборка, Android Lint, модульные тесты, подпись и совместимость с предшествующей APK

**Важно:** проверить физический динамик/вибромотор и особенности оболочки ColorOS можно только на самом телефоне. Не удаляйте текущую версию: установите APK поверх неё. Системные режимы без звука и «Не беспокоить» сохраняют приоритет.

Для ранее беззвучных каналов подтвердите «Включить звук и вибрацию» в настройках BalanceHub и отправьте тестовое уведомление.
