# BalanceHub 1.2.2-rc — тестовые изменения

Это тестовый Pre-release. Стабильной версией остаётся 1.2.1.

- Пользовательские повторения платежей: выбранные даты и несколько чисел месяца.
- Числа месяца в платежах и дни недели в событиях теперь выбираются аккуратными тематическими кнопками вместо стандартных флажков; повторное нажатие снимает выбор.
- В календаре конкретных дат платежа можно выбрать сразу несколько дат, снять выбор повторным нажатием и сохранить все кнопкой «Готово».
- Отдельные начисления с индивидуальной суммой, временем, переносом, пропуском и восстановлением.
- Настройки массового редактирования будущих начислений, сохранение исключений и предварительное подтверждение.
- Пользовательские события с несколькими днями недели, интервалом и выбранными датами; управление посещениями.
- Уведомления начислений с группировкой по времени, защитой от дублирования и переходом к нужной карточке.
- Сумма платежей текущего календарного месяца по фактическим датам с разделением валют.
- Архивирование конечных расписаний по фактическим датам и восстановление карточки без удаления архивного оригинала.

Номер пакета и подпись APK сохраняются, versionCode повышается автоматически GitHub Actions. Изменения проходят проверки перед публикацией.
