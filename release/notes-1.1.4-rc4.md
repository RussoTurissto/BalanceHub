# BalanceHub 1.1.4-rc4 — согласование звука и вибрации с Android

**Предрелиз для проверки владельцем приложения. Не является стабильной версией.**

## Что изменилось
- Проверка звуков и вибрации теперь сопоставляет выбранные в BalanceHub параметры с фактическими параметрами Android: наличие звука, выбранную мелодию, вибрацию, её рисунок и важность канала.
- В настройках каждой категории (**Платежи**, **События**, **Обновления**) появилась кнопка **«Проверить уведомление»**.
- Если Android использует другие параметры, в окне теста можно нажать **«Восстановить»**. Только после подтверждения BalanceHub создаёт новый системный канал с выбранными в приложении сигналами.
- После восстановления приложение повторно читает параметры Android и, если всё соответствует выбору, отправляет тестовое уведомление.
- При ошибке новый канал отклоняется, старый остаётся, а пользователь получает подсказку о системных настройках.
- Сохраняются платежи, события, расписания напоминаний, пользовательские данные и 15 встроенных мелодий.

## Проверка на телефоне
1. Установите `BalanceHub.apk` поверх текущей версии (не удаляйте приложение).
2. Откройте **Настройки → Уведомления → Платежи**.
3. Выберите мелодию и вибрацию в приложении; нажмите **«Проверить уведомление»**.
4. Если есть расхождение с Android, нажмите **«Восстановить»**, затем **«Применить»**; проверьте звук и вибрацию на телефоне.
5. Повторите для «События» и «Обновления». Если звук по-прежнему не воспроизводится, откройте системные настройки канала.

Android может ограничивать звук и вибрацию системными разрешениями, режимом «Не беспокоить», громкостью или настройками прошивки. Автоматические тесты проверяют каналы и доставку уведомлений, но не физический звук динамика и работу вибромотора конкретного телефона.
