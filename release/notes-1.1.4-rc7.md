# BalanceHub 1.1.4-rc7 — диагностика мелодий и точных рисунков вибрации

**Закрытый тестовый предрелиз (Draft Pre-release).** Устанавливается поверх прежней версии с сохранением пользовательских данных.

## Исправления и проверки

- Добавлены независимые уведомления с тремя точными рисунками вибрации:
  **Короткий** (110 мс), **Длинный** (450 мс), **Двойной** (130 мс + 110 мс пауза + 130 мс).
  Каждый тест имеет постоянный ID Android, поэтому системные настройки не сбрасываются после повторного запуска.
- На Android API 35+ новые каналы дополнительно используют `NotificationChannel.setVibrationEffect()`,
  на более ранних версиях — `setVibrationPattern()`.
- Добавлен отдельный тест с системно зарегистрированной WAV-мелодией **«Кристалл»**
  и длинной вибрацией. Это позволяет отличить ошибку стандартной мелодии Android
  от невозможности воспроизвести собственную мелодию BalanceHub.
- В инженерном меню появились **прямые проверки вибромотора** для короткого,
  длинного и двойного рисунков без канала уведомлений.
- Диагностика показывает запрошенный и сохранённый рисунки, наличие
  `VibrationEffect` на Android API 35+, реальную системную мелодию по умолчанию,
  выбранный источник звука, уровень громкости, режим телефона и системный ID.
- Если системная мелодия уведомлений фактически не задана, BalanceHub теперь
  сообщает об этом, вместо того чтобы утверждать, что звук работает.
- Существующие каналы платежей, событий и обновлений **не сбрасываются** при
  установке обновления. Если пользователь сам применяет новые сигналы категории,
  новый канал на API 35+ получает запрошенный `VibrationEffect`.
- Старые тестовые каналы rc6 остаются доступными и не переопределяются.

## Проверка на телефоне

1. Установить новую APK поверх rc6, не удаляя BalanceHub.
2. Перевести телефон в **обычный звуковой режим**.
3. Открыть **Настройки → Уведомления → Платежи** и выполнить последовательно:
   **Тест: Длинная вибрация** и **Тест: Кристалл + длинная вибрация**.
4. Для каждого теста записать результат: есть ли звук и совпадает ли вибрация с длинным импульсом.
5. В инженерном меню выполнить **Прямой вибротест: Длинный**, чтобы сравнить физический отклик
   без канала уведомлений.
6. Если нет звука, открыть системные настройки соответствующего тестового канала и проверить
   мелодию, затем открыть «Результат» того же теста.
7. Повторить в режиме телефона «Вибрация», не изменяя системные настройки рабочего канала.

## Ограничения

Сохранённый `VibrationEffect` и статус `shouldVibrate()` подтверждают лишь настройки
Android API. Реальный звук и рисунок зависят от прошивки, громкости и системных ограничений.
Приложение не может принудительно менять пользовательские настройки существующих каналов.
