# BalanceHub 1.2.5-rc6 (758) — утверждённая верхняя область без переосмысления

Выполнено по окончательно утверждённым изображениям:
- Верхняя зимняя область: ветви, снег, шишка, золотой бант, звезда, бирюзовые
  стеклянные шары и тёплая гирлянда взяты из конкретного утверждённого
  изображения. Три локальных WebP-слоя сохраняют исходные пиксели.
- Красная шапочка с белой меховой опушкой и помпоном взята из того же макета,
  вырезана отдельно и привязана к измеренной позиции заглавной H в BalanceHub.
  Она визуально лежит сверху на букве, шрифт и позиция текста не меняются.
- BalanceHub остаётся отдельным настоящим TextView, полностью читаемым;
  слой гирлянды физически исключён из прямоугольника надписи.
- Никаких изменений геометрии заголовка, карточек, календаря, навигации,
  меню, платежей, событий и пользовательских данных.
- Все ресурсы входят в APK, сеть для зимнего оформления не требуется.

Проверки: четыре Android API 29/30/35/36, тест расположения шапочки и
отсутствия лампочек на буквах, снимки обычных и зимних тем, сравнение
структуры пяти вкладок, unit-тесты, release lint, подпись и совместимость
обновления поверх ранее установленной версии.

Тестовая APK: com.github.russoturissto.buttonapp.app,
versionName=1.2.5-rc6, versionCode=758. Подписывается действующим ключом.
Выпуск выполняется только как артефакт отдельной ветки, без публикации
стабильного релиза.
