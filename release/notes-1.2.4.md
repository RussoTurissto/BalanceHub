# BalanceHub 1.2.4 — стабильная версия

Стабильный выпуск объединяет все изменения тестовых версий 1.2.4-rc1, 1.2.4-rc2, 1.2.4-rc3 и 1.2.4-rc4 на основе стабильной 1.2.3.

## Банки, карты и счета

- Настройки каждого банка собраны в отдельном блоке «Карты и счета · Название банка».
- Показ банка, получение Push-уведомлений и список его карт и счетов настраиваются вместе.
- Подсказка об отсутствии распознанных счетов теперь находится внутри блока соответствующего банка.
- Общая настройка «Доступ Android» сохранена внизу страницы.
- Существующие настройки видимости, распознанные остатки, банковские Push-уведомления и светлая/тёмная темы сохранены.

## Нижняя навигационная панель

- Панель стала компактнее: высота 60 dp, минимальная высота кнопок 54 dp.
- Положение панели согласовано с системными жестами Android и управлением тремя кнопками.
- В том числе при прозрачной панели жестов нижний отступ берётся по фактической границе системной навигации, а не по расширенной области распознавания жестов.
- Зазор над системной навигацией составляет 2 dp; все пять вкладок, подписи и иконки сохранены.

## Установка и обновление

Файл установки: `BalanceHub.apk`. Версия 1.2.4 устанавливается как обновление поверх ранее установленной BalanceHub, без удаления приложения. Перед публикацией GitHub Actions проверяет тесты, совместимость обновления, цифровую подпись и контрольную сумму APK.
