# BalanceHub 1.1.4-rc5 — совместимость каналов уведомлений с Android

**Тестовый предрелиз. Проверка на конкретном телефоне обязательна.**

## Исправления

- Новый канал, создаваемый по явному выбору звука или вибрации в приложении,
  получает ранее не использовавшийся ID (UUID). Android иногда восстанавливает
  предыдущие настройки удалённого канала при повторном использовании ID.
  Ранее созданные каналы и сохранённые настройки автоматически не сбрасываются.
- ID активного канала и количество обнаруженных каналов категории показаны в
  инженерной диагностике. Это поможет выявить переход на другой канал Android.
- Восстановление проверяется повторно после задержки или возвращения в BalanceHub.
  Фраза об успешном создании канала больше не означает подтверждение физического
  звука или вибрации.
- В обычных настройках уведомлений появился переход в общие системные настройки
  BalanceHub — как отдельный уровень настройки в мессенджерах.
- **«Чистый тест Android»** создаёт отдельный канал со стандартной системной
  мелодией и вибрацией по умолчанию, без WAV и пользовательского виброрисунка.
  Тест не изменяет каналы платежей, событий или обновлений. После запуска
  можно открыть настройки именно этого тестового канала и сравнить параметры.
- Добавлены модульные и Android-тесты на уникальность ID и изоляцию проверки.
  Сохранены пользовательские данные, 15 мелодий и установка поверх прежней APK.

## Проверка на телефоне

1. Установите `BalanceHub.apk` поверх предыдущей версии без удаления данных.
2. Откройте **Настройки → Уведомления → Платежи → Чистый тест Android**.
3. Проверьте системное уведомление (звук и вибрацию) и откройте
   **«Настройки тестового канала»**. Посмотрите, включены ли «Звонить» и
   «Вибрировать». После возврата нажмите «Результат чистого теста».
4. Если тестовые сигналы работают, выберите «Кристалл» и «По умолчанию» для
   категории платежей. Проверьте настоящее уведомление.
5. Если канал вновь перестал воспроизводить сигнал, откройте
   **Инженерное меню → Диагностика уведомлений → Состояние звука и вибрации Android**
   и пришлите ID активного канала, звук, вибрацию и ошибки.
6. Для сравнения проверьте **«Общие настройки уведомлений Android»**.

## Ограничения

Android управляет разрешениями уведомлений, режимом «Не беспокоить»,
громкостью, системными настройками каналов и аппаратной вибрацией. Успешный
ответ API или эмуляторных тестов не гарантирует физический отклик устройства.
