# BalanceHub 1.2.3-rc1 — защита приложения

Это тестовый предварительный выпуск. Стабильная версия — 1.2.2.

- Добавлен четырёхзначный код доступа BalanceHub с проверкой и защитой от подбора.
- Вход по системному отпечатку пальца Android (без распознавания лица); при изменении отпечатков требуется повторное включение через код.
- После окна «Что нового» или завершения обучения предлагается добровольно включить защиту.
- Добавлен раздел «Настройки → Безопасность»: изменение кода, вход по отпечатку и повторная блокировка.
- Повторная блокировка: сразу, через 1 минуту, через 5 минут или после блокировки устройства.
- Окна оформлены в светлой и тёмной теме BalanceHub с настоящей иконкой приложения.
- Защита доступна начиная с Android 11. Работа платежей и фоновых напоминаний не изменяется.

Имя APK остаётся BalanceHub.apk. Подпись прежняя; versionCode повышается GitHub Actions.
