# BalanceHub 1.1.4-rc6 — сравнение двух каналов вибрации Android

**Тестовый предрелиз.** Предназначен для диагностики работы звука и вибрации на телефоне с ColorOS.

## Изменения

- Добавлены два независимых теста системных уведомлений с одинаковым стандартным звуком Android:
  1. **Тест: системная вибрация** — Android выбирает рисунок самостоятельно.
  2. **Тест: заданная вибрация** — два явных импульса (180 мс, пауза 120 мс, 220 мс).
- Каждому тесту выделен свой постоянный канал. Повторный запуск использует тот же ID и не пересоздаёт канал, поэтому системные настройки сохраняются между проверками. Если канал удалён из Android, для теста создаётся новый уникальный ID.
- Добавлены отдельные экраны результатов и переход в настройки соответствующего тестового канала.
- Диагностика показывает звуковой режим телефона, значение shouldVibrate() из Android и зарегистрированный рисунок вибрации. Эти значения не выдаются за подтверждение физического отклика.
- В инженерном меню добавлен прямой тест вибромотора без канала уведомлений и без зависимости от настройки выбранной категории.
- **Не изменены** каналы платежей, событий, обновлений, пользовательские мелодии, данные и оформление. Идентификатор приложения и ключ подписи сохраняются.

## Проверка на телефоне

1. Установите новую APK **поверх** предыдущей (не удаляйте приложение).
2. Переведите телефон в **обычный звуковой режим**.
3. Откройте **Настройки → Уведомления → Платежи** и последовательно запустите
   «Тест: системная вибрация» и «Тест: заданная вибрация». Для каждого теста запишите,
   слышен ли звук и чувствуется ли вибрация.
4. Для каждого тестового канала откройте «Настройки тестового канала», проверьте
   «Вибрировать», выйдите назад и откройте тот же канал ещё раз. Сравните состояние
   переключателя. Обратите внимание, что ID канала остаётся прежним.
5. Повторите оба теста в режиме телефона **«Вибрация»**.
6. При необходимости в **Инженерном меню → Диагностика уведомлений** запустите
   «Прямой тест вибромотора без канала».
7. Пришлите четыре результата: обычный режим × два теста; режим вибрации × два теста.

## Ограничения

- Ответ Android API о вибрации не гарантирует физический отклик. Видимый
  переключатель каналов у производителя может отличаться от API.
- Приложение не вправе принудительно переопределять системные ограничения или
  пользовательские настройки канала. Это диагностические тесты, а не обещание исправления прошивки.
