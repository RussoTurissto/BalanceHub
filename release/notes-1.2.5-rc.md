# BalanceHub 1.2.5-rc4 (versionCode 756) — естественный зимний иней

Тестовый APK для просмотра зимнего оформления на реальном Android. Предыдущий
релиз 1.2.5-rc3 остаётся неизменным в своей рабочей ветке, стабильная версия
не публикуется автоматически.

- Изморозь на каждом экране, меню, диалоге, панели и карточке формируется
  по собственному узору из тонких ветвящихся кристаллов. Рисунок не меняется
  при перерисовке отдельного элемента.
- Ледяные кристаллы располагаются преимущественно на краях и в углах, не
  мешают читать баланс, даты, подписи и нажимать кнопки.
- Более натуральный снег на гирлянде, хвое и бирюзовых стеклянных шарах,
  блики тёплых лампочек на стекле. Существующие ветки, шары, золотые звезда
  и бант остаются на местах.
- Заголовок BalanceHub, его отступы, размер шрифта и положение не менялись.
- В календаре, выборе времени, настройках, платежах, событиях и нижней
  навигации сохранено действующее поведение и реальные данные пользователя.
- Автовключение зимней темы — 20 декабря по 10 января включительно.
- Контроль: Android API 29, 30, 35, 36, release lint, JVM-тесты, снимки
  обеих тем, сертификат подписи и совместимость обновления с предыдущим APK.

Тестовая установка: BalanceHub.apk, package
com.github.russoturissto.buttonapp.app, versionName 1.2.5-rc4,
versionCode 756. Пользовательские данные при обновлении не удаляются.
