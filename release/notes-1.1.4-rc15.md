# BalanceHub 1.1.4-rc15 — безопасное переключение звука платежей

- Только категория «Платежи»: смена мелодии и громкости теперь начинается с отдельного пробного системного канала.
- Сначала отправляется реальное тестовое уведомление. Пользователь должен услышать нужную мелодию и подтвердить результат. До подтверждения действующий канал не меняется.
- Если ColorOS сбрасывает мелодию, можно назначить её через системные настройки именно пробного канала и повторить тест; прежний канал при этом сохраняется.
- После подтверждения активируется тот же проверенный канал: новые напоминания о платежах используют его.
- Выбор любого из пяти режимов прямой вибрации в режиме ColorOS не пересоздаёт звуковой канал платежей.
- Отмена смены не влияет на действующие платежи и системные параметры их рабочего канала.
- Сохранены исходные настройки событий и обновлений, методы их уведомлений и расписания.
- Старый подтверждённый канал платежей защищён от автоматической очистки для возможности восстановления.
- Добавлены проверки всех 85 вариантов выбора звука и вибрации платежей в тестовых каналах Android.

Ограничение: Android/ColorOS владеет системным каналом и может игнорировать автоматически назначенную мелодию. Поэтому после ручного выбора звука в Android требуется фактическое прослушивание и подтверждение. Успешный ответ API Android сам по себе не доказывает физический звук.
