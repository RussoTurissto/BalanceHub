# BalanceHub 1.1.4-rc8 — обход сбоя ColorOS 17 (OnePlus 13)

**Закрытый тестовый релиз**: GitHub Draft Pre-release. Обновление поверх предыдущей APK, без удаления платежей, событий и сохранённых настроек.

## Новое

- В «Настройки → Уведомления» появился **переключатель «Совместимость с ColorOS»**. По умолчанию он выключен: на Xiaomi и других устройствах ничего не меняется.
- Включение и выключение требуют подтверждения. По подтверждению создаются новые каналы для платежей, событий и обновлений. Существующие ручные настройки этих каналов Android могут сброситься; пользователь предупреждается об этом до операции. Если настройка новых каналов не удалась, старые остаются действующими. Отдельные заглушённые пользователем категории остаются заглушёнными.
- В режиме совместимости системные каналы **не вибрируют**: им остаются текст уведомления и выбранная мелодия. Платёжные и календарные уведомления, обновления и диагностические напоминания вызывают вибрацию **непосредственно** через Android Vibrator с назначением `USAGE_NOTIFICATION`. Время и рисунок взяты из настроек BalanceHub, в том числе длинный импульс 450 мс.
- Двойной сигнал исключён: если пользователь включает системную вибрацию самого канала, дополнительная прямая вибрация не запускается.
- Прямая вибрация пропускается при выключенных уведомлениях приложения или категории, отключённом вибросигнале BalanceHub, режиме телефона «Без звука» и действующем «Не беспокоить». Режим телефона «Только вибрация» поддерживается. Не происходит принудительного обхода ограничений системы.
- Добавлены журнал последнего запуска прямого вибросигнала и проверки фоновых тестовых напоминаний через две минуты.

## Что сделать на OnePlus 13

1. Установить APK **поверх** rc7, не удалять приложение.
2. Открыть **Настройки → Уведомления → Совместимость с ColorOS**, включить и подтвердить пересоздание каналов.
3. Убедиться, что для категории «Платежи» выбрана нужная мелодия и «Длинный» вибросигнал. В Android у канала вибрация должна оставаться **выключенной**, иначе включится штатный сигнал вместо прямого.
4. В обычном звуковом режиме выполнить **«Проверить уведомление»** для платежа. Ожидается звук канала и длинная прямая вибрация; если звук отсутствует, проверьте настройку мелодии этого канала. BalanceHub не включает звук вопреки выбору «Без звука» в Android.
5. В инженерном меню запустить **«Тест платежа через 2 минуты»**, затем свернуть приложение и заблокировать экран. Проверить звук и длинную вибрацию. В журнале прямой вибрации посмотреть последний статус.
6. Повторить в режиме телефона «Только вибрация».
7. Для возвращения к стандартной Android-вибрации выключить режим совместимости и подтвердить пересоздание каналов.

## Что не изменено

Расписание и содержимое платежей и событий, функции банков, подпись APK, package ID, стандартное поведение на Xiaomi и механизм закрытых релизов GitHub.

## Известные ограничения

- Команда `Vibrator.vibrate()` с атрибутом уведомления может быть отклонена производителем на заблокированном экране; успешный вызов API сам по себе не доказывает физический отклик.
- Мелодия по-прежнему принадлежит системному каналу Android. Если ColorOS сбросит её после ручного изменения настроек канала, приложение не станет самовольно воспроизводить звук или переопределять системное отключение; потребуется выбрать мелодию вручную или подтвердить восстановление канала.
- Не применяется обход для «Не беспокоить» и системного беззвучного режима.
