# BalanceHub 1.2.4-rc1 — единые разделы банков

Тестовое обновление оформления раздела «Настройки → Банки». Текущая стабильная версия — 1.2.3.

- Для каждого банка предусмотрен свой раздел «Карты и счета · Название банка».
- Переключатель отображения банка, настройка получения Push и его карты/счета собраны в одной карточке.
- При отсутствии распознанных счетов подсказка отображается внутри блока соответствующего банка.
- Общая настройка «Доступ Android» остаётся внизу страницы.
- Сохранены существующие настройки видимости, распознанные остатки и получение банковских Push-уведомлений.
- Сохранены оформление и отступы BalanceHub в светлой и тёмной темах.

Имя установочного файла: BalanceHub.apk. Подпись и возможность обновления проверяются GitHub Actions.
