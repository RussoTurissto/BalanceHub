# BalanceHub 1.1.4-rc17 — звуки событий и обновлений

## Новое

- Проверенный механизм автоматического воспроизведения WAV для OnePlus/ColorOS
  теперь доступен для уведомлений событий и обновлений.
- Для каждой категории отдельный выбор мелодии, громкости, вибрации и
  подтверждение через пробное уведомление до переключения рабочего канала.
- Один общий foreground-проигрыватель для выбранных WAV, без двойного
  воспроизведения системного канала.
- Сохраняется предыдущий рабочий канал для восстановления после неудачной пробы.
- Обновления продолжают проверяться через GitHub, события используют
  существующее расписание. Прямой вибросигнал остаётся раздельным.
- Добавлены безопасные тесты и диагностика автоматического звука для категорий.

## Сохранность платежей

Проверенная сборка 688 зафиксирована в ветке
backup/balancehub-688-verified-payments. Платежи не меняют собственный
алгоритм уведомлений и данные. Подтверждённые настройки сохраняются.

## Проверка на устройстве

После установки проверьте события и обновления через «Звук» → «Тест»,
а для событий дополнительно реальное напоминание при выключенном экране.
Android может ограничивать запуск foreground-службы из фона, поэтому тест
на устройстве необходим даже после успешной сборки.
