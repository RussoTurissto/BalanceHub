# BalanceHub 1.2.5-rc5 · versionCode 757 — зимняя тема без перестройки интерфейса

Тестовая ветка: feature/balancehub-winter-rc5. Релиз не является стабильным,
не сливается автоматически в main и не публикуется в публичном канале.

## Внешний вид
- Вкладки Главная, Балансы, Платежи, События, Настройки сохраняют одинаковую
  компоновку и порядок элементов в обычном и зимнем оформлении.
- Удалены отдельные зимние раскладки Платежей и пустых Событий. Добавление
  сверху, сворачиваемый блок предстоящих и отдельный архив — как обычно.
- В Настройках восстановлена обычная последовательность: Оформление,
  Безопасность, Мобильная связь, Банки, Уведомления, Обновления,
  Помощь и диагностика, О приложении.
- Для Балансов сохранён подзаголовок и неизменные отступы.
- Шрифт и положение BalanceHub в верхней части не изменены.
- Новогодняя графика: высокодетализированные масштабируемые хвойные иглы,
  естественные сугробы на ветке и проводе гирлянды, бликующие бирюзовые
  стеклянные шары, снежные детали золотого банта и звезды.
- Низкокачественный пиксельный ресурс перестал использоваться для отрисовки
  шапки. Декор рисуется сглаженными векторами в плотности устройства.
- Уникальная, менее навязчивая изморозь на каждом элементе с устойчивым
  рисунком на повторном отображении; ледяные узоры не закрывают подписи.

## Проверки при выпуске
- Сравнение иерархии и положения функциональных элементов при включении
  и отключении зимнего режима на пяти вкладках.
- Проверка раскрытых Платежей и Событий, скриншоты обычных и зимних тем.
- Unit-тесты, release lint, Android API 29/30/35/36.
- Подписанный APK с package com.github.russoturissto.buttonapp.app,
  versionName 1.2.5-rc5, versionCode 757.
- Проверка установленного сертификата и обновления поверх 1.2.1; другие
  более новые APK с кодом не выше 757 должны обновляться без переустановки.
